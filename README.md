# LOOT HUNTERS CC — 黑晶礦坑
建立日期：2026-10-13

依照 `D:\LOOT HUNTERS\GAME_DESIGN.md` 的首版設計做出的可玩版本（Claude Code 施工版）。

## 怎麼開始玩

- 在這個資料夾裡**點兩下「開始遊戲.bat」**，或直接用 Chrome／Edge 開啟 `index.html`。
- 不需要安裝任何東西。字型會從網路載入；沒網路時改用電腦內建字型，遊戲照樣能玩。
- 進度自動存在這台電腦的瀏覽器裡。選單可以匯出、匯入存檔。

## 玩法重點

- **營地**：選難度、每波怪數（1–20）、主動／掛機、速度（1–4 倍），買紅水藍水後出征。
- **地城**：每層是由多個洞室與坑道組成的大礦坑，鏡頭跟著角色。附近沒怪時角色會自己往沒去過的黑暗處探索，
  怪物會從黑暗中冒出來追你（遠處只看得到紅色眼睛）。左上角小地圖顯示探索過的範圍。
  角色會自己走、自己打，你只要看準時機點技能（或按數字鍵 1–8）。
  技能全部來自身上的裝備，每招會自己挑方向與目標。
- **清完一層**：背包是 5×5 的格子，裝備有不同形狀。可以拖曳、右鍵或 R 旋轉、拖到金色區出售。
  之後選「繼續下一層」或「撤退回營地」。第 5 層有隨機四種頭目之一。
- **死亡**只會失去這一趟還沒賣掉的裝備；經驗、已賣的金幣、出發前的裝備都保留。
- **掛機**：在「掛機設定」調整技能規則與喝藥門檻。掛機倒下會自動把每波怪數降 1 再試；
  連續成功 3 趟再往回加。
- **倉庫批量出售**：可一鍵勾選普通／精良以下／非升級裝備後一起賣，也可逐件勾選（或按住 Ctrl 點選）；清層畫面也有一鍵出售。
- **星盤**：166 點、6 個區域、18 個星座。每個星座是「小星 → 中星 → 大星」，集滿整個星座再加獎勵。
  點遠處的星點會標出路線，可以整條一起買；上方「主題」可以讓火焰、防禦等相關星點發光。滾輪縮放、拖曳移動。
- **工坊**：花金幣強化裝備（一定成功，上限依稀有度 +3～+12），或挑一條屬性重骰（只重抽數值，或換成別種屬性）。
- **盔甲分類**：頭、身、手、腳都分重甲／輕甲／布甲。四件同一類有套裝加成：重甲護甲 +15%；輕甲閃避 +10%、移動速度 +5%；
  布甲最大法力 +15%、冷卻縮減 +5%。倉庫可以依類別篩選。
- **換裝外觀**：英雄穿什麼就長什麼樣（頭盔、盔甲、手套、靴子、盾牌、箭袋、晶球），稀有度越高顏色越華麗，傳說以上多一件披風。
  每種武器的攻擊動作不同（匕首連刺、長劍橫掃、戰鎚重砸、拉弓、舉杖施法）。地城畫面可用滑鼠滾輪調整大小（預設 1.5 倍）。
- **畫面**：角色有呼吸、走路、攻擊、受傷動作，手上拿著實際裝備的武器；地圖有燈籠、礦車軌道、墓碑、棺材等小物件，
  沼澤邊緣自然、水面有波紋；小物件只是裝飾，不會擋路，也不影響戰鬥結果。
- **傳奇寶物**：20 件有固定名字與特效的寶物（例如碎顱者、霜心法杖、貪婪之戒），數值隨掉落等級成長。頭目最容易掉、精英怪次之，
  難度與深淵規則越兇越容易出現。營地「寶物圖鑑」記錄收集進度；還沒拿到的會顯示部位與掉落地點。掛機背包放不下的傳奇寶物會寄回營地，倉庫滿也不會被自動賣掉。
- **掉寶排場**：史詩以上有光柱，傳說以上畫面會頓一下，傳奇寶物有金色光柱、大字與專屬音效；清層時好裝備用翻牌的方式出現。
- **深淵規則**：深淵每趟隨機抽 1～3 條規則（狂暴、堅韌、枯竭、火雨、蜂群……共 12 種），每條都附帶掉寶與經驗加成；可以花金幣重抽，掛機每趟自動重抽。
- 視窗縮小時戰鬥會繼續；完全關掉遊戲後，下次打開會依最近幾趟的成績結算離線經驗與金幣。

## 首版內容

- 四個章節，各有普通／困難／惡夢，打贏惡夢後開放無上限的「深淵」階級（每階怪物等級 +3，掉寶更好）：
  - 「黑晶礦坑」（5 層）
  - 「骨沼墓渠」（6 層）：礦坑普通通關後開放。有拖慢腳步的沼澤、死後留毒沼的怪、會治療同伴的巫師，以及 4 隻新頭目。
  - 「熔鐵工坊」（6 層）：骨沼普通通關後開放。地上有會灼傷人的熔岩（角色會盡量繞開），怪物多半打火焰傷害，3 隻新頭目，
    頭目專屬技能「隕火」「熔鐵斬」與 3 種專屬特殊能力。
  - 「星隕觀測所」（7 層）：熔鐵工坊普通通關後開放。天上會落下星隕（地上先出現預告，角色會自己閃開），
    地上有星光（站在裡面法力回復 3 倍，缺魔時角色會自己走過去）。怪物多帶雷電與冰霜，3 隻新頭目（星語大祭司、隕星巨獸、墮星天使），
    頭目專屬技能「星落」「冰隕箭」與 3 種專屬特殊能力（星盾、星辰導引、隕星回響）。
- **難度深度**：
  - 困難、惡夢、深淵會扣你的元素抗性（困難 −15%、惡夢 −30%、深淵每階再多扣 5%），抗性可以扣到負的。
  - 精英怪：名字會發光，帶烈焰／冰封／雷殛／吸血／迅捷／鐵壁／分裂等能力，必掉稀有以上。
  - 比怪物高 5 級以上，每多 1 級經驗少 20%（最少 10%），變強要靠裝備與星盤。
  - 技能耗魔隨技能來源裝備的等級提高，回魔、減耗魔與藍水變得重要。
  - 掛機可勾選「自動挑戰更高的深淵」：連勝 2 趟往上一階，倒下退回一階。
- 背景音樂即時合成：標題、營地、四個章節各一首，頭目出現時切換戰鬥曲；營地右上角可分別調整音樂與音效音量。
- 4 種小怪（鎬工、礦甲獸、碎石弩手、晶塵祭師）與 4 種頭目（監工、黑晶巨像、晶脈寄生者、掘地母獸），
  頭目大招前地面會出現發光預告；主動模式在加速時會自動放慢，留給你反應時間。
- 8 個裝備部位、6 種稀有度、14 種裝備技能 + 8 種頭目專屬技能、24 種特殊能力、20 件傳奇寶物、166 點星盤；共 16 種小怪、14 隻頭目。
- 所有圖案（像素角色、怪物、頭目、裝備圖示）與音效都由程式即時產生，不需要任何外部素材檔。

## 給開發者

| 檔案 | 內容 |
|---|---|
| `js/data.js` | 所有遊戲內容與數值（技能、怪物、星盤、經濟） |
| `js/sim.js` | 地城戰鬥規則（不碰畫面，可在 Node 中測試） |
| `js/game.js` | 營地操作、出征流程、掛機循環、存檔、離線收益 |
| `js/render.js` / `js/sprites.js` | 地城畫面、光影、特效與像素美術 |
| `js/ui.js` | 營地分頁、背包拖曳、報告 |

```
node --test tests/rules.test.js      # 45 項核心規則測試
node tools/sim_run.js 20 1 0         # 無畫面連續出征 20 趟，看節奏與成長
node tools/compare_modes.js 3 11     # 比較預設掛機 vs 熟練手動的通關時間
```

已知待調：熟練手動比預設掛機快的幅度，加入探索走路後約在 6%～12%（設計目標 30～50%），
需要實際試玩後再調整技能數值與預設掛機規則。
